# RoboCode

Atividade proposta para a prática de versionamento de código em grupo.

## Pontos trabalhados:

* **Branch** – Trabalho com diferentes ramificações do repositório.
* **Versionamento** – Comandos utilizados para subir o projeto no GitHub.
* **Colaboração** – Trabalho em equipe com separação de tarefas e uso de múltiplas branches.

## Branches

> Foi criada uma branch principal para o desenvolvimento do robô. Em seguida, foram adicionadas novas branches para trabalhar em partes separadas, como `estilo` e `melhorias`.


* `Main` - Branch principal de produção.
* `Estruturas` – Branch principal de desenvolvimento, onde o robô foi criado e aprimorado.
* `Estilo` – Branch voltada para a estilização do robô.
* `Melhorias` – Branch para possíveis melhorias futuras no robô.

## Desenvolvimento

Em geral, o versionamento do código foi tranquilo. A parte mais desafiadora foi entender o **código de outras pessoas**, o que tornou o desenvolvimento um pouco mais difícil, já que exige interpretação e adaptação.
